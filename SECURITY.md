# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

If you find a security issue in Aether, please report it privately.

Do **not** open a public issue for security problems.

Use GitHub Private Vulnerability Reporting (Security tab), or contact the maintainer via the profile listed on the repository.

We aim to respond within a few days.

## Notes

- Aether stores log-derived templates in a local SQLite baseline. Treat that file as sensitive.
- Reports may contain redacted command fragments; avoid sharing them publicly if they could still leak context.
